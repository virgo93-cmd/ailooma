## WordPress duplicate-content status

NEEDS HUMAN ACTION

Observed on 2 September 2026:

- `https://cms.ailooma.biz.id/why-laptop-keeps-freezing-fix/` returned `200`.
- The CMS page exposed an indexable robots directive and a canonical pointing to the CMS URL.
- `https://cms.ailooma.biz.id/robots.txt` advertised the WordPress sitemap.

Safe configuration required in WordPress:

1. Open **WordPress Admin → Settings → Reading**.
2. Enable **Discourage search engines from indexing this site**.
3. Save Changes.
4. Do not disable or password-protect `/wp-json/`; the Next.js REST integration must remain public.
5. Recheck a CMS article and confirm its HTML contains `noindex`.

No plugin is required for this first-party WordPress setting. WordPress documents that the setting adds a `noindex,nofollow` robots meta directive when the theme calls `wp_head`. Google requires crawlers to be able to access a page to see `noindex`, so do not rely only on a robots.txt `Disallow` rule.

After enabling it, use Google Search Console URL Inspection or the Removals tool if CMS URLs have already entered the index.
